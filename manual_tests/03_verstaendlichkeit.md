# 03 – Verständlichkeit

Ob ein Satz verständlich ist, kann kein automatischer Test beurteilen. Die Beispielrechnungen zeigen
zusammen jedes Ergebnis und jeden Hinweis des Tools (das prüft `tests/beispiele/beispiele.test.ts`).
Sie lesen die Texte so, wie ein Mandant sie liest.

## MT-04: Ergebnisse und Hinweise der Beispielrechnungen lesen

**Voraussetzung:** Die Seite mit den Beispielrechnungen ist geöffnet (Adresse: siehe
[README](README.md)). Das Tool ist in einem zweiten Fenster geöffnet.

1. Laden Sie auf der Seite mit den Beispielrechnungen die erste Datei herunter.
   - **Danach:** Die Datei liegt in Ihrem Ordner „Downloads“. Der Browser öffnet sie nicht selbst.
2. Ziehen Sie die Datei auf die Fläche „Rechnung hierher ziehen“.
   - **Danach:** Oben steht das Ergebnis, darunter gegebenenfalls die Pflichtangaben.
3. Lesen Sie das Ergebnis, die Erklärung darunter, jeden Hinweis in der Tabelle der
   Pflichtangaben und den Abschnitt „Rechnerische Prüfung“. Öffnen Sie dazu auch die zugeklappten
   Teile („… Angaben, die nur in besonderen Fällen nötig sind“, „Technische Angaben“).
   - **Danach:** Notieren Sie jeden Satz, den Sie nicht beim ersten Lesen verstehen. Notieren Sie
     auch jeden Satz, der so klingt, als sei die Rechnung „in Ordnung“ oder „geprüft“ – das Tool gibt
     nur Hinweise.
4. Vergleichen Sie das Ergebnis mit der Spalte „Was sie zeigt“ auf der Seite mit den Beispielen.
   - **Danach:** Beides passt zusammen. Wenn nicht, notieren Sie die Nummer der Datei.
5. Nehmen Sie die nächste Datei und beginnen Sie wieder bei Schritt 1.
